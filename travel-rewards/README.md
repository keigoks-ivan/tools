# 里程路線

台灣使用者的繁體中文航空里程、信用卡、飯店點數與會籍挑戰規劃工具。
入口為 `/home.html`，工具位於 `/travel-rewards/`，預設先顯示互動會籍樹狀圖。純靜態網頁，不需要建置或外部套件。

## 目前範圍

底稿基準日：2026-10-25；銀行入口選定欄位於2026-10-27補核。底稿含16條候選路線、14張信用卡／版本及66條規則。介面另合併滙豐旅人三卡比較，共17張卡／版本、59種候選玩法、18張子圖、106條規則、157筆來源及104項研究目標；36項仍待研究。各來源保留自己的查核日期，不把同機構多頁當成兩方互證。
這些數字包含未完成研究、歷史活動、條款差異與待核線索，不代表完整市場或所有資格已確認。
未連接即時獎勵機位、稅費或房況；使用者需填入實際報價。規劃條件只保存在目前瀏覽器，沒有帳戶服務或資料上傳。

## 檔案

- `data.json`：公開來源、規則、卡片、原始候選路徑與研究範圍。保留查核日期、有效期限、來源代碼及缺口。
- `content.mjs`：整理後的路線、步驟及獎勵資產名稱。
- `core.mjs`：資格排除、未知條件、費用及試算邏輯。
- `app.mjs`：介面互動、搜尋、最多三項比較、詳情與來源。
- `fields.mjs`：原始規則欄位與代碼的中文顯示名稱。
- `core.test.mjs`：重要資格邊界、截止日、成本及轉點限制測試。
- `tree-data.mjs`：SAS完整候選鏈、萬豪與新航、華航卡三張基礎路線樹，以及每段的當期查核與官方來源。
- `network-data.mjs`：共用資源、候選玩法、來源、條件與補充研究紀錄。
- `extensions-data.mjs`、`partner-views.mjs`：小樹點、JAL、聯航、Hyatt／Aeroplan、IHG地區快軌與來源研究；所有玩法併入共同清單。
- `cube-data.mjs`、`cube.mjs`：18個直接轉點出口、整批最低量試算、卡別差異、2027版本及分開顯示的限時活動。
- `stay.mjs`：12種方案各自的品牌、房價、管道、房晚及時序規則；節點與全站共用住宿檢查和比較表。
- `hotel-partners-data.mjs`、`hotel-partners-views.mjs`：飯店點數使用、滙豐兩種積分、ALL×Qatar一次性會籍快線、ALL×Flying Blue常設合作與來源研究。
- `hotel-use.mjs`：四計畫使用規則、已建檔轉入來源、同條件住宿價值試算。切換計畫清除上家的報價，不預設房況或銀行點數替代價值。
- `hotel-partners.test.mjs`：ALL排他連結、來源待核、名額與首次活動、特定海外卡、酒店使用與價值試算邊界。
- `eligibility.test.mjs`：MEA認列差異、小樹點單位／年度、IHG嚴格門檻、挑戰次數與新分支邊界。
- `network-core.mjs`、`network.test.mjs`：複選資源、來源限制、同時必備條件、排除、跨圖出口與資料完整性。
- `network-views.mjs`：運通、萬豪卡、萬豪挑戰／正常定級、航空、酒店點數、ALL與Qatar六張投影子圖。
- `tree-core.mjs`、`tree.test.mjs`：分支追蹤、不可達目標、圖形完整性與縮放邊界。
- `tree.mjs`、`tree.css`：可拖曳縮放、選起點、節點條件側欄、手機步驟版及可分享連結。
- `setup-core.mjs`、`setup.mjs`、`setup.test.mjs`：三步設定（卡片依銀行分組、會籍點選、點數），以及「我的路線」的分組規則 `planGroups`。
- `ihg-hyatt-data.mjs`：IHG與Hyatt會籍門檻、Hyatt五級點數表、台灣銀行轉點查核、IHG／Hyatt會籍子圖與欄位中文名。
- `flow.css`：歡迎頁、我的路線、路線步驟頁、手機底部選單與三步設定的樣式。

## 更新資料

先核對當期官方完整條款，再更新規則和來源；同機構的不同頁面不能算獨立機構互證。外部分享與客服個案保留線索身分，不能直接視為目前可申請。
開始規劃依已填的卡片／會籍判斷是否有對應起點；起點不足、已排除、官方有差異或已截止的路線只列在預設收合的其他路線，不列為目前可接上的路線。
不同有效期的條款保留各自版本。來源無法讀取、官方互相矛盾、資格來源不明、實際名額未查時，保留缺口，不改成已核可。
新增欄位時同步更新 `fields.mjs`，維持中文呈現。新增可判斷的前提時同步更新 `core.mjs` 的資格判斷及必要邊界測試。
更新介面、模組或資料後，遞增 `index.html` 與 `app.mjs` 的快取版本。發布前檢查桌面與手機、全部分頁、對話框、比較表、試算及來源連結。

樹狀圖的路徑亮起只表示前後關係，不會把待核、歷史、地區或來源限制變成已核准。SAS範例保留GHA／Wyndham、BW、Choice、Scandic、土航及約旦分支；Choice並非接到SAS的前提。原文網址與日期未提供，四晚Scandic挑戰及2026土航受理條件保留待核。約旦當期一般條款1.4(j)排除串接配對來源，圖中相應分支標記排除；不能只憑FAQ列有SAS或土航就判定整串可完成。

分享格式為 `#tree=sas-chain&start=visa&node=sas`。合法節點以資料定義為準，未知值不會建立新路線。分享網址不包含使用者的信用卡、消費或個人帳戶資料。

## 共用路線網與既有規劃頁

路線網以 `OPPORTUNITIES` 作候選玩法與條件的共同清單，子圖節點綁定資源與機會ID。相同資源可顯示跨圖出口，但持卡、領取會籍、點數餘額和申請核准分開處理。來源、已用登錄與目前等級需另填；未知不當作符合。

多資源狀態只存本機 `imq-reward-network-v1`，不放分享網址。預設沒有資源；只採使用者在設定或路線圖明確勾選及填寫的項目。2026-10-30 起舊的單卡規劃表單已拿掉，「我的路線」直接讀這份狀態，`imq-reward-routes-v1` 不再使用。同一計畫保留一個目前等級。未核准會籍不由卡片自動產生。

既有「依條件規劃」仍保留16條路線及單卡篩選；其餘玩法與多資源判斷以路線網為入口，不宣稱已遷移舊頁。CUBE在獨立點數路線提供卡別／Level差異，未混入尚未完整查核的信用卡年費比較。舊頁已提供對應目標的路線網連結。

正常會籍房晚、合作挑戰實住晚數、銀行轉入獎勵點數分開。萬豪卡150萬／100萬升等以信用卡年度；正常25／50資格房晚以曆年。MEA正常定級自2026/2/12起一合格晚1 ENC；JAL合作明文排除；新航合作未取得個別MEA認列確認，顯示待核。其他挑戰不套用上述任一方案的品牌規則。

小樹點以信用卡點數為資產，生活點分開。2026有14航空、4飯店直接出口；世界卡三家專屬比例排除亞洲萬里通世界卡。2027只列9家調整，未列及世界卡專屬比例顯示待核。基本轉點試算不自動加限時回饋；IHG升等按基本點嚴格「超過」4萬／6萬推算，不能用加碼達標。

會員確切等級與舊「白金以上未細分」分開保存。鈦金／大使可提供白金以上能力給既有新航分支，但不由舊的白金以上反推鈦金。Aeroplan一般高階每年一次Hyatt住宿挑戰，指定高階主卡每年兩次，條件按資源判斷。新活動的生效／截止依台北日期判斷；圖上靜態來源查核仍以資料基準日為準。

ALL航空合作改用目前實際連結的航空與距前次連結時間。舊的相對欄位「是否連其他航空」無法區分Qatar與FB，不能遷移成已連任一家，保留待填。滿12月也須先解除舊連結；不會將兩個互斥合作同時判定已接通。資源表只問目前子圖需要的來源／一次性條件，其他已存答案保留。

ALL×Qatar快線按當期專屬條款：ALL Gold至Qatar Silver、Platinum／Diamond以上至Qatar Gold；反向Qatar Gold至ALL Silver、Platinum至ALL Gold。須首個合格活動、未用過且有名額。非正常累積來源未明示接受，標待核；反向國內住宿有行銷與條款差異，不保證台灣一晚觸發。

ALL×FB常設首次獎勵最多2資格晚＋10XP，沒有直接送高卡。專屬手動ALL→FB 1:1優先於一般自動轉換章的殘留數字；不建立自動轉點。全點數住宿觸發首次XP、混合支付航班、部分入帳文字與轉點增量／上限仍有缺口。

飯店使用與銀行轉點門檻分開。萬豪住五付四免最低點數晚；Hilton銀卡以上全點數標準房第五晚；ALL官網1,000點起、台灣等地櫃檯500點起；IHG第四晚為指定Chase卡而非白金通用福利。本圖只核Premier Select入口，其他海外卡未普查。試算只用使用者提供的實際報價，不再次扣除官方已計的連住優惠。

## 2026-10-27 起點補齊

102項資源共用同一份清單；新增旅人三卡、星展飛行四卡、中信ANA六卡，以及ANA／亞洲萬里通／新航哩程。`bank-entries-data.mjs`保留當期選定欄位、來源、卡片比較及累積入口；`bank-entries-views.mjs`將持卡、累積、餘額與兌換分段呈現。旅人無限與ANA無限可提供Visa無限卡能力，其他卡不由名稱推定卡組織高階資格。持卡不增加點數或會籍，明填零餘額不作為轉點前提。

卡名移除「已持有」，原申請梯次截止改放補充說明。匯豐／滙豐及HSBC可搜尋相同項目。信用卡、會籍與點數各有其他起點記錄，保存在本機資源的`unlisted`，最長各500字；只作待核筆記，不參與資格、餘額或推薦判斷。完成才保存，略過不改資料；來源、互斥連結及一次性條件仍依各路線核對。這些入口不代表所有銀行、卡片或獎勵票規則均已查核。

## 2026-10-30 流程改版與 IHG／Hyatt

- 選單改為四項：我的路線、路線圖、信用卡、更多（試算與資料庫收進更多）。手機版選單固定在底部。
- 第一次進站不再自動跳出設定，改顯示歡迎頁與簡介；設定由「開始：選我手上的卡」開啟，縮成三步（卡片、會籍、點數），目標改在「我的路線」切換。
- 「我的路線」依起點分成：接得上、起點對上還缺條件、有一段條款還沒查實、其他路線。點開是步驟頁，依路線圖節點順序列出每一段的條件、費用、期限與官方來源；手機版全螢幕。`#route=ID` 直接開啟。
- 節點狀態把「須申請或核准」和「條款還沒查實」分開：後者用橘色虛線（`unverified`），目前用在 Wyndham、Scandic、Mastercard 酒店配對、滙豐卓越紅利與國泰世華 Life。
- 信用卡頁把使用者有的卡排前面，每張卡標出能接幾條路線；卡片詳情列出路線連結。資料庫狀態依今天日期判斷是否過期，規則代號只放在提示文字。
- IHG：Club 到 Diamond 五個等級資源、正常累積、受邀企業快軌（同頁晚數矛盾）、洲際大使（付費線索）。Hyatt：Discoverist、正常累積、五級點數表與 Points + Cash。台灣運通 MR、星展飛行積金、滙豐、國泰世華四家頁面都沒有 Hyatt 轉點；其他發卡行只搜尋過，不寫成沒有。
