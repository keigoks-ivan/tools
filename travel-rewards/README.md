# 里程路線

台灣使用者的繁體中文航空里程、信用卡、飯店點數與會籍挑戰規劃工具。
入口為 `/home.html`，工具位於 `/travel-rewards/`。純靜態網頁，不需要建置或外部套件。

## 目前範圍

資料基準日：2026-10-24。首批含16條候選路線、14張信用卡／版本、66條規則、74筆來源紀錄及90項研究目標。
這些數字包含未完成研究、歷史活動、條款差異與待核線索，不代表完整市場或所有資格已確認。
未連接即時獎勵機位、稅費或房況；使用者需填入實際報價。規劃條件只保存在目前瀏覽器，沒有帳戶服務或資料上傳。

## 檔案

- `data.json`：公開來源、規則、卡片、原始候選路徑與研究範圍。保留查核日期、有效期限、來源代碼及缺口。
- `content.mjs`：整理後的路線、步驟及獎勵資產名稱。
- `core.mjs`：資格排除、未知條件、費用及試算邏輯。
- `app.mjs`：介面互動、搜尋、最多三項比較、詳情與來源。
- `fields.mjs`：原始規則欄位與代碼的中文顯示名稱。
- `core.test.mjs`：重要資格邊界、截止日、成本及轉點限制測試。

## 本機檢查

在儲存庫根目錄執行：

```sh
python3 -m http.server 8872 --bind 127.0.0.1
node --test travel-rewards/core.test.mjs
```

開啟 `http://127.0.0.1:8872/travel-rewards/`。不用執行根目錄的 `build.py`。

## 更新資料

先核對當期官方完整條款，再更新規則和來源；同機構的不同頁面不能算獨立機構互證。外部分享與客服個案保留線索身分，不能直接視為目前可申請。
開始規劃依已填的卡片／會籍判斷是否有對應起點；起點不足、已排除、官方有差異或已截止的路線只列在預設收合的其他路線，不列為目前可接上的路線。
不同有效期的條款保留各自版本。來源無法讀取、官方互相矛盾、資格來源不明、實際名額未查時，保留缺口，不改成已核可。
新增欄位時同步更新 `fields.mjs`，維持中文呈現。新增可判斷的前提時同步更新 `core.mjs` 的資格判斷及必要邊界測試。
更新介面、模組或資料後，遞增 `index.html` 與 `app.mjs` 的快取版本。發布前檢查桌面與手機、全部分頁、對話框、比較表、試算及來源連結。
