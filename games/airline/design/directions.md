# 天青航空 v2：兩個改版方向

建議選 A「即時航網」，再從 B 拿兩樣東西：樞紐設施卡和情境挑戰。A 改變的是每一秒看到的畫面，飛機真的在飛、旅客在機場排隊、每班落地跳出賺賠，這正是 Fly Corp 和 Mini Metro 被稱讚的地方。B 加的是選單和系統，深度夠，但回合會變長，新系統也要重新校準損益。

兩個方向的經濟模型都沿用現在的 model.mjs，課程內容不變，改的是呈現方式和玩家能動的東西。

研究依據見 research.md。有一點要先更正：AirTycoon 4 的商店頁沒有提到 3D 地球，3D 地圖是 AirTycoon 5 才有的選項；Fly Corp 用的是平面地圖。兩個方向的 3D 地球是我們自己的設計，材質用 NASA 公開影像。

## 方向 A：即時航網

時間會走、可以暫停和快轉。地球上看得到每一架飛機、每一群等不到位子的旅客。一個月約 60 秒，月底照舊結算。

### 核心循環
1. 從樞紐拉一條線到城市就開了航線，從底部機庫把飛機拖上去決定班次。參考：Mini Metro（拉線、底部資源列）、Fly Corp（開航線）。
2. 時間開始走，飛機沿航線飛，每班落地跳出這一班賺或賠多少。參考：Airline Manager 4（飛機落地才入帳）。
3. 機場旁的旅客點點越積越多，代表座位不夠；點點很少，代表飛機太大或票太貴。深藍是商務客，淺藍是觀光客。參考：Fly Corp、Mini Metro（排隊旅客）。
4. 新聞在月中出現，遊戲自動暫停，等你決定避險、跟價或加班。參考：Airline Manager 4（油價市場）。
5. 月底結算，每條航線一張損益卡，原因沿用現在的一句話。累積營收到門檻就解鎖新地區。參考：Fly Corp（地區解鎖）。

### 畫面上有什麼
- 3D 地球：淡藍海洋、米白陸地，看得到地平線。用 NASA Blue Marble 做地形明暗，Natural Earth 畫海岸線。
- 航線：藍色賺錢，紅色虧錢，線越粗班次越多；對手航線是灰色虛線。
- 飛機：飛行模擬遊戲的 MQ 機型 3D 模型，由上往下看，有尾跡和地面影子。
- 機場：旁邊的旅客點點、「沒搭上 4,651 人」這類標籤；樞紐周圍是轉機旅客。
- 航線小卡：載客率條加一條損益平衡線，例如「上海浦東 載客 96%，平衡 113%，坐滿也虧」。
- 左上：現金、本月淨利率（對照業界 3.9%）、全公司載客率。上方中間：日期和變速鈕。
- 右側：新聞卡、選中航線的詳細卡（座位條、成本組成、班次與票價調整）。
- 底部：機庫列（MQ-72／MQ-320／MQ-350／租一架），右下是「這一年學到的事」。

### 三個讓人記住的時刻
1. 開場鏡頭從雲上拉到台灣，地球慢慢轉，第一架天青飛機從桃園起飛。
2. 油價大漲那個月，沒避險的航線一起轉紅，落地數字由綠變紅；鎖過價的航線只是淡紅。
3. 第一次開長程線，寬體機越過太平洋，航線消失在地平線後面，再從北美那一側出現。

### 現有的課怎麼教
| 課 | 在 A 裡看到什麼 |
|---|---|
| 載客率與損益平衡 | 每條航線的座位條和紅色平衡線；落地數字直接告訴你這班賺賠 |
| 坐滿也會虧 | 上海線排隊的人最多、飛機全滿，每班落地仍是負數 |
| 空蕩的寬體機 | 洛杉磯線座位條只填到 56%，平衡線在 63% |
| 燃油與避險、避險成本 | 新聞卡先預告，避險滑桿；漲價那個月航線轉紅的程度不同 |
| 季節 | 2 月淡季時機場點點明顯變少，暑假變多 |
| 廉價對手、價格戰 | 對手虛線出現，你機場旁的點點有一部分改走對手航線 |
| 轉機與樞紐效果 | 樞紐旁繞圈的轉機點點；接上支線後，幹線的點點變多 |
| 飛機閒置 | 機庫裡沒派出去的飛機變灰，月底帳單照扣租金 |
| 天候、罷工 | 受影響的航線變虛線停飛，飛機停在機場 |
| 經營模式（全服務或廉價） | 第 6 個月董事會卡；換成廉價後座位變多、機身換色 |
| 時段、利率、景氣、疫情、復甦、租機市場 | 十年模式，每季壓縮成約 90 秒，事件卡照常出現 |

### model.mjs 沿用與新寫
- 沿用：需求、票價彈性、對手、成本、事件、一句話原因、測試與機器人玩家。月底照舊呼叫 simulateTurn，帳和現在一模一樣。
- 新寫：月內播放層，把一個月的班次、旅客、損益拆成每一班來畫，只負責顯示、不改帳。
- 新寫：月中改的班次與票價從下個月生效，畫面標「下月起」，這樣模型不用改。若要立即生效，需在模型加按天數比例計算與測試。
- 新寫：地區解鎖資料、地球渲染、航線與飛機覆蓋層、新的 HUD。

### 手機
- 直式：地球滿版，上方現金與變速，下方抽屜放選中的航線和機庫。
- 橫式：抽屜改放右側。拖曳在手機上改成先點城市、再點機型。
- 地球材質在手機改用 2k 版，影像加遮罩約 1 MB 以內。

### 規模
- 新增約 5 到 6 個 JS 模組，改 ui.js 和 style.css。
- 資產約 3 MB：地球影像 1.3 MB、陸地遮罩 1.5 MB；three.js 和飛機模型 repo 裡已經有。
- 代理工作量約 5 到 7 天：渲染 2 天、播放層與模型接線 1.5 天、HUD 與手機版 2 天、測試與實機驗收 1 天。

### 風險
- 時間一直走，玩家可能只看動畫不思考。對策：每個事件和月底都自動暫停，預設一個月約 60 秒。
- 一年模式決策不多，月中可能只剩看飛機。對策：排隊點點和落地數字會讓人想加班或改價。
- 手機效能：地球只在鏡頭移動時重畫，飛機和點點畫在 2D 層。
- 十年模式要把半年壓成 90 秒，事件會比較密。

## 方向 B：航空大亨

保留回合制，一季一回合，但每一季能做的經營決定變多：蓋樞紐設施、配置座位、買租二手飛機、看油價市場、和幾家電腦對手搶航線。畫面是夜色中的寫實地球加上密集的管理面板。

### 核心循環
1. 每季開始先看事件和上季財報。參考：AirTycoon 4（回合制，一季一回合）。
2. 調整航線網：開關航線、選機型、班次、票價，這部分和現在相同。
3. 經營樞紐：升級航廈（時段上限）、貴賓室（商務客）、維修基地（維修費少 30%）、油庫（先買油存著）。參考：AirTycoon 4（樞紐才能蓋維修基地和貴賓室）。
4. 管機隊：買新機、租機或買二手機，設定商務、豪華經濟、經濟艙的座位數。參考：AirTycoon 4（二手機、升級飛機）、Airline Manager 4（座位配置）。
5. 按「結束本季」，地球播放這一季的航班摘要，接著是損益卡、成就和情境進度。參考：Airline Manager 4（成就）、Fly Corp（情境挑戰）。

### 畫面上有什麼
- 寫實 3D 地球：白天用 NASA Blue Marble，夜半球用 Black Marble 城市燈光，晨昏線上有暖色。
- 發光航線：藍色賺錢、紅色虧錢；對手航線是白色虛線；航線旁的小卡寫班次占比，例如「東京成田 37%，雲錦航空每週 10 班、輕羽航空 7 班」。
- 上方：日期（第 4 年夏季，20 季中的第 7 季）、現金、淨利率、載客率與平衡點、油價、品牌聲望、「結束本季」。
- 左側：分頁列，包括總覽、航線、機隊、機場、油料、行銷、對手、成就。
- 右上：樞紐卡，一張可以蓋東西的機場小圖，下面列出四項設施和它們的效果，以及本場時段用量。
- 右下：機隊卡，飛機 3D 圖、座位配置圖（16／24／150）、「10 架全是租的，建議不超過 30%」的提醒。
- 左下：情境挑戰「亞洲轉機王」、油價市場曲線（×1.84，你實際付 ×1.44）。

### 三個讓人記住的時刻
1. 夜半球亮起城市燈光，往德里、孟買的航線從白天飛進黑夜。
2. 航廈擴建：虛線框變成新的登機門，新飛機滑進去停好，時段上限增加。
3. 油價暴漲那一季，油價曲線往上衝，鎖價的綠色虛線留在下面，跳出成就「撐過第一次油價暴漲」。

### 現有的課怎麼教
| 課 | 在 B 裡看到什麼 |
|---|---|
| 載客率與損益平衡 | 航線小卡和航線分頁照舊列出兩個數字；頂部列有全公司數字 |
| 坐滿也會虧、空蕩的寬體機 | 損益卡沿用一句話原因；機隊卡顯示每架飛機的座位與實際載客 |
| 燃油與避險 | 油價市場卡：曲線、鎖價比例、油庫存量 |
| 季節、景氣、疫情、復甦 | 季初事件卡，季末損益卡 |
| 廉價對手、價格戰 | 對手分頁列出每家電腦對手在哪些航線、幾班、票價高低 |
| 轉機與樞紐效果 | 樞紐卡寫轉機旅客人數和占比；情境目標也以轉機比例計分 |
| 飛機閒置、租機市場 | 機隊卡的租機比例警示；閒置飛機在機隊分頁標示 |
| 時段 | 航廈等級決定本場時段上限；擁擠機場顯示「時段已滿」 |
| 利率 | 買機貸款列在機隊與財報 |
| 經營模式 | 開局選擇，之後可改，要付改裝費 |
| 新增：維修成本、商務客與票價 | 維修基地讓維修費少 30%；貴賓室與座位配置改變商務客比例和平均票價 |

### model.mjs 沿用與新寫
- 沿用：整個回合流程、需求、對手、成本、事件、一句話原因、測試與機器人玩家。
- 新寫並要重新校準：設施效果（維修費、商務客需求、時段上限、存油）、座位配置（座位數和票價組合）、二手機（買價低、維修費高）、更多電腦對手（從 2 家增加到 4 家）、情境目標檢查、成就、跨局保存。
- 每加一個系統都要補測試，確認合理玩法仍落在淨利率 3% 到 8%、差的玩法仍然會虧。

### 手機
- 直式：地球占上方約一半，下方抽屜分頁（樞紐、機隊、油價、對手），最底是分頁列和「結束本季」大按鈕。
- 面板多，手機上要切很多頁；每頁只放一個決定。

### 規模
- 新增約 10 個模組，模型程式多 30% 到 40%。
- 資產約 3.5 MB：白天影像 1.3 MB、夜光影像 0.8 MB、遮罩 1 MB。
- 代理工作量約 9 到 12 天：模型擴充與校準 3 到 4 天、面板 4 到 5 天、地球 1.5 天、測試 1.5 天。

### 風險
- 決策變多，一回合變長，玩家花在選單的時間多過看懂損益的時間。
- 新系統都要重新校準，否則某一個設施會變成必勝解。
- AirTycoon 系列玩家抱怨過的東西都不做：遊戲結束年份、很難關掉的航線、降落小遊戲、付費現金。
- 畫面密，第一次玩的人需要引導。

## 建議

選 A，再加 B 的兩樣：
1. 樞紐設施卡，只放三項，每項對應一課：維修基地對應維修成本，貴賓室對應商務客與票價，航廈對應時段。放在月底結算畫面，不另開選單。參考：AirTycoon 4。
2. 情境挑戰卡，例如「亞洲轉機王」，給第二次玩的人一個目標。參考：Fly Corp。

理由：
- 使用者要的是更好玩、畫面更驚豔。A 把每一秒的畫面變成會動的地球，這是兩個方向裡改變最大的部分。
- A 不用改經濟模型，現有測試和校準都能保留；B 要加 6 到 7 個新系統，每個都要重新校準。
- 研究裡被抱怨最多的是選單多、畫面平（早期 AirTycoon 評論說介面單調、靠選單操作；AirTycoon 5 的評論抱怨介面和樞紐系統），B 比 A 更接近這些問題。

什麼情況下該選 B：如果目標改成讓玩家反覆玩十年模式、玩很多局，B 的深度比較適合；A 的新鮮感在玩過兩三次後會下降。
