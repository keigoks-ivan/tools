# 小小美髮師 · 自由造型與作品收藏

正式遊戲：https://tools.investmquest.com/salon/
遊戲入口：https://tools.investmquest.com/games/

純 HTML / CSS / ES modules、Canvas 2D、Pointer Events，無框架與建置步驟。

## 本機與手機開啟

在此目錄執行：

```sh
python3 -m http.server 8866 --bind 0.0.0.0
```

電腦開 http://127.0.0.1:8866/。手機或 iPad 接同一個 Wi-Fi，開 `http://電腦區網IP:8866/`。正式網址可直接使用。遊戲依可用視窗與 safe-area 排版，支援直式、橫式、分割視窗，旋轉保留造型；DPR 最多 2。工具按鈕至少 64 CSS px。

## 遊戲流程

- 選客人、挑靈感，完成髮色、髮長、髮飾三個小願望。願望以髮色球、髮型圖和髮飾圖表示，完成項目亮起綠色勾勾；進度依實際作品更新，完成會灑花提示拍照。可隨時切換自由創作，沒有倒數、失敗或強制評分。
- 主畫面的大骰子直接抽驚喜造型，組合一至兩種髮色、三種髮長和八種飾品；連續抽不會重複上一張。抽卡只換願望，保留作品，並自動選好第一個染色工具。草稿和照片會保存抽到的卡片。
- 完成三個願望後拍照，可收集客人 × 主色的 18 張角色貼紙。同一張不重複領取；照片存滿時不發獎，刪除照片不會刪掉貼紙。貼紙簿從靈感、作品集或照片左上角的小冊子開啟；未收藏的格子可直接接指定客人與顏色的挑戰，已收藏的格子可開啟對應作品。照片右箭頭直接換下一位客人並抽新靈感。
- 髮色進度將每段髮絲歸入最接近的一種調色盤顏色，避免藍色同時算成綠色、橘色同時算成金色。
- 上方：客人、抽驚喜、綁髮、貼紙、作品、拍照。貼紙冊直接開啟收藏；點願望頭像可挑原本的六種靈感。點髮色、髮長或飾品願望，直接選好所需工具及尚未完成的顏色／目標飾品。願望完成後相機跳動，底部顯示相機 → 貼紙圖解，可直接拍照領取。工具與顏色使用原生 HTML 按鈕，保留輔助名稱、選取狀態和鍵盤焦點；右上角提供玩法說明。
- 下方（橫向在右側）直接顯示九個工具：洗頭、沖水、梳髮、剪髮、長長、染髮、捲髮、拉直、飾品。剪刀支援點一下或拖過髮絲；生髮水可按住生長；染髮可局部塗色，也可整頭染色。
- 選工具後，頭髮上有手指點／拖示範，六秒後消失，實際操作時立即隱藏；點底部工具手勢圖可重看。示範不修改作品，偏好減少動態時顯示靜態手指。洗頭按住或拖過髮絲搓泡泡，沖水洗掉；泡泡跟著髮束移動，最多 180 顆，草稿、照片與撤銷保存泡泡。洗頭不會洗掉染色。捲髮棒做柔軟波浪、拉直工具梳出直髮，保持髮絲弧長、髮根、髮圈固定點與染色，短髮或固定髻不會強行變形。
- 剪髮時顯示願望的參考長度。綁髮後用髮束弧長判斷進度，避免馬尾與丸子頭讓長髮被誤判成短髮。
- 梳理會帶動附近髮節，髮根保持圓順；綁髮沿頭形收束，短髮依剩餘長度縮小擺幅，盤髮以巢狀弧線收進髮髻。變形後使用沿髮束連續的細髮絲材質，避免原插畫的亮暗紋路被拉成橫向接縫。
- 點上排綁髮進入自由綁髮：拖大髮圈到頭髮上，或直接點頭髮綁住附近髮束；左右可分別操作，也能在頭頂收成一束。拖已有髮圈換位置，點一下鬆開，拖到下方可移除；顏色色塊選髮圈顏色，小頭像開現成髮型，打開的髮圈圖示放下全部頭髮。髮圈觸控區至少 64 CSS px。太短、臉部或空白區域的放置保留原造型；撤銷、照片與草稿保存自由位置。鍵盤 Enter／空白可從髮圈架建立，方向鍵移動髮圈，Enter／Delete 鬆開。
- 綁髮選單提供雙馬尾、高雙馬尾、泡泡辮、雙丸子頭、低側馬尾、側邊高馬尾、高馬尾、公主頭和放下，預覽使用客人當前的頭髮。頭髮不足時提示先長長；剪到髮圈上方會鬆開。
- 髮飾有蝴蝶結、花、星星、蝴蝶、愛心、月亮、皇冠、珍珠項鍊（預設中間往下垂）。點一下放置，拖曳移動，點既有髮飾轉 45 度，拖旋轉把手可任意轉向，拖到下方垃圾桶移除。
- 左下角撤銷最近 8 次實際修改，也支援 Ctrl/Cmd+Z。空白處操作不消耗紀錄。右下角重設需確認，重設後仍可撤銷。
- 拍照存入作品集，可繼續編輯或下載 JPEG。刪除需再按一次。相簿最多 48 張，不覆蓋舊照片。
- 每位客人未完成的造型自動保存於這台裝置的 IndexedDB。素材與儲存不阻塞遊戲；圖片失敗有向量人物備援，儲存鎖住、不可用或寫入失敗會顯示提示，仍可遊玩與下載照片。
- 旋轉、失去指標捕捉、切換工具、開選單及切到背景均結束當前手勢並保存，避免工具黏住。舊存檔中損壞的髮束、髮圈與髮飾會被檢查。

## 結構

- `studio.css`、`js/studio.js`：原生 HTML 操作介面、願望進度、玩法說明與可鍵盤選取的選單覆層。
- `js/studio-art.js`：向量美髮店、拱形鏡面、座椅、披肩與人物備援；背景獨立於角色，不再伸展整張客人插畫。
- `js/play.js`：驚喜造型產生、存檔檢查、18 張貼紙與完成資格。
- `js/goals.js`：六個願望的髮色覆蓋、實際弧長與髮飾判定。
- `js/hair.js`：208 條可獨立剪染的髮束、Verlet 兩子步、距離約束、臉部邊界、方向排序、速度限制、綁髮固定點、可序列化髮束狀態。
- 初始每束 10–14 節點；綁髮會視需要在髮圈的實際弧長處分割節點，生長與綁髮都不超過 16 節點。剪斷保留精確交點，斷髮逐節掉落並有限量、淡出。
- `js/looks.js`：客人與六張造型卡資料；`js/data.js`：基本客人與六色調色盤。
- `js/foam.js`：依附髮束的泡泡、搓洗、沖水與存檔檢查；`js/tools/care.js`：洗頭、沖水、捲髮與拉直。
- `js/tools/`：統一 `onDown / onMove / onUp / drawOverlay` 工具介面。
- `js/ornaments.js`：髮飾繪製與拖放工具；`js/replay-ui.js`：圖像選單、綁髮選單、相簿與拍照流程。
- `js/memory.js`：IndexedDB 照片、各客人草稿及失敗時的記憶體備援。
- `js/layout.js`：螢幕排版、固定物理世界與 Pointer Events 座標轉換。
- `js/sfx.js`：真實錄音掛鉤。`assets/sfx/` 沒檔案就保持安靜，不合成音效，不請求不存在的錄音。
- 執行時只載入同站本地素材，不用外部字型、追蹤、API 或素材服務。

## 驗證

```sh
node tests/core.mjs
node tests/layout.mjs
node tests/replay.mjs
node tests/experience.mjs
node tests/natural-hair.mjs
node tests/free-tying.mjs
node tests/play.mjs
node tests/care.mjs
node tests/stability.mjs 300
```

測試精確剪斷、局部染色、生長上限、梳理後形狀保留、實際綁髮、弧長保留、剪開髮圈、照片狀態還原、無效保存資料與 10 種螢幕排版。
`tests/stability-report.json` 是 300 秒混合剪染、生長、梳理、綁髮、拆髮操作的物理數值報告。不是實體 iPad 效能量測。`natural-hair.mjs` 另外檢查 24 組客人／綁法的伸長、自由髮尾折角、髮根弧線、反覆梳理、染色保留與舊綁髮草稿遷移；物理測試不能取代畫面檢查。

## 美術

依使用者後續要求，採用內建 ImageGen 產生的本地插畫背景、客人表情與髮絲材質。頭髮仍由可變形的程式髮束繪製，不以預製照片替換剪染結果。新客人素材為 `assets/art/guest-honey.png` 與 `assets/art/guest-peach.png`，提示與來源記錄在 `assets/art/SOURCES.md`。圖像選單與飾品使用 Canvas 畫法。

## 已知限制

- 自由綁髮使用附近髮束收束，最多六組；頭髮要足夠長才能移到目標位置，放在臉部或沒有髮絲的地方不會綁住。泡泡辮與髮髻為二維髮束造型，仍可用九種現成髮型。長度不足的髮束保留散髮。
- 梳理、綁髮使用穩定的二維髮束模型，不是完整的三維真實髮絲碰撞。髮頂、極短剪髮和髮圈附近仍可見部分材質接縫。
- 生成的表情在五官細部、頸部接合處仍可能有微小差異，已校正新客人的表情位置。
- 尚未加入吹風機、化妝或動物客人。
- 未在實體中階手機或 iPad 上量測 60fps；瀏覽器模擬不能代替真機測試。
