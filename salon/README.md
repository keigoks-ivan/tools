# 小小美髮師 · 第 1 階段

## 開啟

不需要建置、套件或 API key。在此資料夾執行：

```sh
python3 -m http.server 8866 --bind 0.0.0.0
```

電腦開啟 http://127.0.0.1:8866/；iPad / 手機連接相同 Wi-Fi，使用電腦的區網 IP 與同一個埠。直式遊玩。正式部署只需要 index.html、js/、assets/。

## 玩法

畫面沒有文字、數字、分數、倒數或失敗條件。底部依序是剪刀、生髮水、染色噴罐、梳子、重來。點色塊會直接拿起噴罐。選工具後在頭髮上拖曳；噴罐與生髮水也可按住使用。剪刀顯示開合，噴霧有方向，梳子隨拖動轉向。剪髮會先驚訝再笑；平時每 3–6 秒眨眼。

## 實作

- Canvas 2D，Pointer Events，DPR 上限 2；單一有效指標避免雙指互相干擾。
- 208 條髮束；初始 10–14 節點，生長上限 16。節點各自持有 RGB。
- Verlet 兩個子步、每子步五次距離約束、速度限制、髮束向下排序、臉部邊界限制。
- 剪刀對手勢與節點線段求交，保留精確交點，剪下的帶子逐節掉落到地板。落髮與粒子有數量上限，舊落髮淡出。
- 生髮從髮尾逐步延長，再增加節點；顏色延續髮尾。噴霧只混合半徑內節點的顏色。
- 客人資料在 js/data.js。工具模組統一 onDown / onMove / onUp / drawOverlay，只有選中工具接收事件；按住工具可另有 update。
- 依後續「盡量生圖」指示，背景、客人表情、工具底座與髮絲材質使用內建 ImageGen 產生的本地素材。髮型仍是可變形、可剪斷、可染色的程式髮束，沒有切換預製髮型圖片。
- js/sfx.js 只有真實錄音掛鉤。assets/sfx/ 為空時完全安靜，也不請求不存在的聲音。加入錄音後，將檔名列入 available 集合。
- 執行時只讀同站本地素材；沒有外部字型、分析追蹤或音效合成。

## 驗證與限制

```sh
node tests/core.mjs
node tests/stability.mjs 300
```

core.mjs 檢查精確交點、局部染色、髮尾生長、節點上限、梳理穩定與重來。
stability-report.json 記錄 300 秒連續混合操作的數值結果。這是物理模型測試，並不等同真實 iPad 硬體壓力測試。

開發驗收保存了四張 390×844 瀏覽器截圖。在瀏覽器手機尺寸以 Pointer Events 拖曳驗證四工具、重來與選色；另檢查 iPad 尺寸。沒有真實 iPad / 中階手機硬體可供量測，因此不宣稱所有裝置都能固定 60fps。

美術仍有改進空間：髮頂小範圍接縫、極短剪髮後的髮尾邊緣，以及大幅生長後的分層輪廓，還沒有達到參考插畫逐筆繪製的精緻度。生成的四張表情細部亦可能有微小差異。

僅第 1 階段；未加入洗頭、吹風、化妝、配件、拍照、照片牆或新客人。

## 美術來源

所有新素材由內建 ImageGen 生成，沒有下載外部素材。

- scene.png：以核准參考圖為編輯目標，保留店內、臉、披肩、椅子與工具底座，移除所有頭髮，供可操作髮束覆蓋。
- blink.png / surprise.png / happy.png：只更換同一位客人的表情，其餘構圖保持。
- hair-texture.png：滿版直向栗棕髮絲表面，手繪焦糖高光與巧克力陰影，無臉、無背景、無文字，用於基礎髮束材質。
- hair-plate.png：以實際初始截圖提取並精修透明髮絲圖層，維持相近位置與尺寸，加入自然層次、光澤與髮尾。程式取樣這張材質並貼合各條髮束。
