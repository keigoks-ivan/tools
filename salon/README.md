# 小小美髮師 · 自由造型與作品收藏

正式遊戲：https://tools.investmquest.com/salon/
遊戲入口：https://tools.investmquest.com/games/

純 HTML / CSS / ES modules、Canvas 2D、Pointer Events，無框架與建置步驟。

## 本機與手機開啟

在此目錄執行：

```sh
python3 -m http.server 8866 --bind 0.0.0.0
```

電腦開 http://127.0.0.1:8866/。手機或 iPad 接同一個 Wi-Fi，開 `http://電腦區網IP:8866/`。正式網址可直接使用。遊戲依可用視窗與 safe-area 排版，支援直式、橫式、分割視窗，旋轉保留造型；DPR 最多 2。工具按鈕至少 64 CSS px。

## 不識字也能玩的流程

- 上方由左至右：選客人、造型靈感、拍照、相簿、髮飾。
- 三位客人有不同膚色、眼睛、披肩、初始長度與髮色，各有普通、開心、驚訝、眨眼表情。
- 六張圖像造型卡提供配色、長度和髮飾靈感。可以自由偏離願望，沒有評分、對錯、倒數或失敗。
- 原本四工具：剪刀、生髮水、顏色噴罐、梳子。 選到的工具和顏色後面會有一顆跳動的粉紅愛心。點色塊就拿起噴罐；在髮飾模式中，色塊選擇下一個飾品的顏色。
- 梳子沿手指路徑逐撮帶動頭髮，更新整理後的形狀。放手後有重力與阻尼，保留梳理結果；已綁緊的部分受髮圈約束，仍能梳理自由垂下的髮尾。
- 髮飾有蝴蝶結、花、星星、蝴蝶、愛心、月亮、皇冠和珍珠。選圖案後在頭髮上放置或拖移；拖到下方出現的垃圾桶區域可移除。數量沒有限制。 碰一下髮飾會轉 45 度；最後碰過的髮飾旁邊有旋轉把手，拖著繞圈可以轉到任何方向（項鍊也能直放、斜放）。
- 上方第 5 顆（綁頭髮的小女生圖示）打開綁髮選單，每格是這位客人現在的頭髮綁起來的預覽：雙馬尾、高雙馬尾、泡泡辮、雙丸子頭、低側馬尾、側邊高馬尾、高馬尾、公主頭、放下。髮飾面板左上角也能切過去。實際髮束收攏，髮根和髮圈都是約束點，保留髮長與逐節顏色。頭髮太短時拿出生髮水提示；不強迫長度不足的髮束穿過臉。剪到髮圈上方會讓那撮脫離。
- 左下角回轉箭頭可撤銷最近 8 次操作。工具列右側圓箭頭重設目前客人的頭髮與飾品，亦可撤銷。
- 相機拍下實際作品。照片下方鉛筆可還原為可繼續操作的造型、下載圖示存 JPEG、右箭頭換客人。垃圾桶需再點一次紅色垃圾桶才刪除。
- 每位客人的未完成造型自動保存。相簿保存最多 48 張，不會自動覆蓋舊作品；滿時相機會帶回相簿。保存於該裝置、該瀏覽器的 IndexedDB，沒有帳號與雲端同步。清除網站資料會移除作品；儲存無法使用時顯示小警示圖示，當次遊戲仍可繼續，也能下載照片。

## 結構

- `js/hair.js`：208 條可獨立剪染的髮束、Verlet 兩子步、距離約束、臉部邊界、方向排序、速度限制、綁髮固定點、可序列化髮束狀態。
- 初始每束 10–14 節點；綁髮會視需要在髮圈的實際弧長處分割節點，生長與綁髮都不超過 16 節點。剪斷保留精確交點，斷髮逐節掉落並有限量、淡出。
- `js/looks.js`：客人與六張造型卡資料；`js/data.js`：基本客人與六色調色盤。
- `js/tools/`：統一 `onDown / onMove / onUp / drawOverlay` 工具介面。
- `js/ornaments.js`：髮飾繪製與拖放工具；`js/replay-ui.js`：圖像選單、綁髮選單、相簿與拍照流程。
- `js/memory.js`：IndexedDB 照片、各客人草稿及失敗時的記憶體備援。
- `js/layout.js`：螢幕排版、固定物理世界與 Pointer Events 座標轉換。
- `js/sfx.js`：真實錄音掛鉤。`assets/sfx/` 沒檔案就保持安靜，不合成音效，不請求不存在的錄音。
- 執行時只載入同站本地素材，不用外部字型、追蹤、API 或素材服務。

## 驗證

```sh
node tests/core.mjs
node tests/layout.mjs
node tests/replay.mjs
node tests/stability.mjs 300
```

測試精確剪斷、局部染色、生長上限、梳理後形狀保留、實際綁髮、弧長保留、剪開髮圈、照片狀態還原、無效保存資料與 9 種螢幕排版。
`tests/stability-report.json` 是 300 秒混合剪染、生長、梳理、綁髮、拆髮操作的物理數值報告。不是實體 iPad 效能量測。

## 美術

依使用者後續要求，採用內建 ImageGen 產生的本地插畫背景、客人表情與髮絲材質。頭髮仍由可變形的程式髮束繪製，不以預製照片替換剪染結果。新客人素材為 `assets/art/guest-honey.png` 與 `assets/art/guest-peach.png`，提示與來源記錄在 `assets/art/SOURCES.md`。圖像選單與飾品使用 Canvas 畫法。

## 已知限制

- 僅支援低側馬尾和雙馬尾，還沒有辮子、髮髻或任意位置綁髮。長度不足的髮束會保留散髮；髮圈位置固定於安全的臉部下方或兩側。
- 梳理、綁髮使用穩定的二維髮束模型，不是完整的三維真實髮絲碰撞。髮頂、極短剪髮和髮圈附近仍可見部分材質接縫。
- 生成的表情在五官細部、頸部接合處仍可能有微小差異，已校正新客人的表情位置。
- 尚未加入洗頭、吹風機、捲髮棒、化妝或動物客人。
- 未在實體中階手機或 iPad 上量測 60fps；瀏覽器模擬不能代替真機測試。

## 發佈

GitHub Pages，來源 `keigoks-ivan/tools` 的 `main`。只發佈 `index.html`、`js/`、`assets/` 與說明、測試。使用 `release/publish-checkout` 的乾淨工作目錄，保留原始倉庫其他未完成工作。不執行倉庫的 `build.py` 或舊 `deploy.sh`。
