# 小花食堂：自由操作的料理廚房 v6

2026-10-03。玩法核心從固定點按流程改為可操作的食材、刀子和鍋具。孩子自己拿食材、切、搬、下鍋、調火、攪拌、翻炒、打果汁、盛盤和餵食。冰箱、砧板、爐台和餐桌始終可自由往返；沒有操作次數門檻或自動過關。

## 工作台

冰箱用完整的大食材圖片，一次顯示六樣或四樣。拿食材後出現在砧板；可以拿多樣，也可以邊煮邊回冰箱加料。

刀子隨手指移動。只有切線碰到食材才分割，空砧板不算切菜。切線位置決定兩塊的大小；原食材圖像與切面保留在各塊上。切塊具有獨立位置、旋轉和速度，可以繼續切，也可以搬動和逐塊下鍋。換成手後拖動食材，或點一塊再點鍋子；拖到上方冰箱可放回。倒入按鈕可把整塊砧板的食材倒進鍋，沒有必須切完的判定。牛奶、麵粉與白飯以倒出內容處理。

平底鍋、湯鍋和果汁機各自保留食材，換工具不會清空另一個鍋。平底鍋與湯鍋開火後依火力及時間逐漸變熟，移動鍋鏟／湯匙推動實際食物；拖動鍋柄能翻炒。食物遇到鍋邊會回彈，軟接觸避免全部堆在同一位置。爐台旋鈕可旋轉調火，工具列可點小火、大火或關火。油、水、鹽可隨時加入。熟度到頂後維持可食用外觀，不產生燒焦懲罰。

牛奶和麵粉在平底鍋形成可推動的麵糊／鬆餅，隨熟度由淡色變金黃。果汁機只在按住開關時旋轉，食材逐步縮小並混合；放開立即停。新的食材加入後仍需自己打碎。想盛盤時直接倒出，盤上保留自己切的食材和熟度。飲料呈現在杯中，料理可拖給朋友；朋友會對水果、食材和調味呈現不同表情。吃完後換下一位朋友，其他工作台的食材仍可繼續玩。

## 幼兒操作與畫面

操作區使用食材、工具、火焰和朋友圖片，沒有閱讀要求。工具只需大範圍手勢；直接點食材也能在當下位置切一刀。砧板使用整個可用高度，切線和搬動座標與畫面保持一致。390×844、320×568 和 844×390 有各自排版；橫向把工作台導航與工具放到兩側。

靜態圖片提示及可重播手勢示範協助辨識動作。按鈕保留中文無障礙名稱，Canvas 提供工作台與食材描述；鍵盤可操作刀子、翻炒、果汁機及餵食。減少動態設定停止提示與轉場動畫，直接操作的食材移動保留。

## 實作與狀態

simulation.js 產生各食材的輪廓、沿切線裁切多邊形，並保持面積與原圖紋理座標；每塊食材是同一個物件，由砧板移到鍋，再移到盤。切割與移動是簡化的二維幾何和有界物理，不是完整流體或剛體模擬。renderer.js 用 Canvas 畫工作台、動態食物、工具、液體、火焰與蒸氣，沿用 art.js 的原創 SVG 食材。尺寸與座標隨畫面比例調整，爐台放大 25%。沒有新增套件或第三方圖像。

model.js 和 voice.js 沿用 v3。既有聲音偏好、朋友和招待次數保留；工作台食材、切塊、火力和鍋內狀態於重新整理時清空，避免舊版流程進度與新物件結構混用。版本快取為 v6；沿用 /little-kitchen/ 的 GitHub Pages 發布。

切菜和倒入使用合成接觸音，正在操作的爐台可播放煎炒／煮湯音，果汁機馬達隨按住開關啟停。靜音、大人說明、背景頁面及指標取消停止相應聲音；音訊測試使用模擬物件。食材英文仍用原有同站女聲 WAV，操作不依賴語音。

```sh
node little-kitchen/tests/interaction.mjs
node little-kitchen/tests/model.mjs
node little-kitchen/tests/voice.mjs
```
