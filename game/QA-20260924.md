# HUNTR/X 驗收記錄 — 2026-09-23／24

本輪將首關美術、戰鬥節奏、觸控修正與資源優化整合。測試使用本機版本及原生 Chrome，全程先開啟靜音。這不是手機實機或所有設備的效能保證。

## 實際 Chrome 操作

- 首頁、開始、三名角色選擇、開場對話、移動、攻擊、重擊、跳躍、閃避與武器切換已有操作覆蓋；Chrome 沒有重現先前的主程序關閉。
- 手機模擬 667 × 375 橫向：以觸控拖曳移動，攻擊、閃避及武器切換有效；直向旋轉提示可顯示。當時發現直向提示背後仍繼續戰鬥，已改為暫停並加入實際主迴圈與恢復流程的回歸測試。
- 首關三段突圍、連段擊殺與大絕可以運作。舊的分散生成限制仍可能超過預期人數，本輪改為所有生成入口共用 18 名活躍敵人的上限，含出場中的敵人。
- 四關場景均已在 Chrome 載入。第二關防衛目標啟動並倒數，第三關限時試煉啟動並倒數，第四關裂口實際受到重擊傷害（55 → 50.08）。
- 使用開發入口加速完成目標、調低頭目 HP 後，首關與最終關均能由大絕擊敗頭目並進入勝利狀態；首關結算的下一關按鈕成功載入第二關。死亡後重試也已操作。此項驗證不等於四關正常難度完整通關。
- 維持靜音時，音樂快取為空、沒有啟動 AudioContext。診斷期間暫時使用無敵／回血避免操作開發工具時死亡；重新整理會清除，未加入正式程式。

## 效能測量與界限

透過 Chrome Console 暫時包裝 `composer.render` 記錄連續幀時間，結束後恢復原函式。以下不是同場景、同敵人數的嚴格 A/B 對照：

| 狀態 | 實測 | 解讀 |
| --- | --- | --- |
| 手機模擬，667 × 375、pixel ratio 1.3、Mira、15 名敵人，6 秒 | 約 60 FPS、p95 幀間隔約 17.7 ms | 使用桌機的 CPU/GPU，不能當作手機實機成績；測於後續模型合併前 |
| 桌面，1365 × 870、pixel ratio 2、Zoey、自動普攻與一次大絕，8 秒 | 約 48.8 FPS、p95 約 33.6 ms、13 名敵人 | 尚未達到穩定 60 FPS；測於部件合併與排程修正前 |
| 桌面原部件繪製，15 名敵人 | 每幀約 675–677 次繪製、303,666–303,858 三角形；提交繪製的 CPU 時間約 3.64 ms | CPU 提交時間不包含完整 GPU 完成時間，不能單憑此數字判定瓶頸 |

後續優化包含相同骨架共用、同材質／同骨架的敵人部件合併，以及 60 FPS 排程抖動修正。它們保留模型、骨架動畫、貼圖像素、解析度、抗鋸齒和陰影設定；不以降低解析度換取數字。

最後的部件合併版本已在 Chrome 成功重新載入至 Zoey 開場。繼續操作時 Mac 鎖定，工具無法解鎖，因此**最終版本的大絕效能複測，以及修正後的直向暫停→橫向恢復實際操作，仍待完成**。不能把上面的舊測量標示成最終版本成績。

測試過程未觀察到遊戲本身的載入、WebGL 或 shader 例外；Console 有既存非同步訊息通道錯誤，另有兩次診斷程式將循環物件轉 JSON 的錯誤，後者已改為只讀純數值。這些結果沒有證明先前 Chrome 主程序當機的確切原因。

## 資料保留與傳輸預算

- Maria GLB：11,821,932 → 7,896,492 bytes。2048 × 2048 base-color 改為無損 WebP，測試比對解碼後 RGBA，並比對幾何、骨架與保留動畫。
- 新店面圖集：1,738,638 bytes，保留生成原圖 1254 × 1254 的全部像素，8 格圖集供既有 24 面店面共用。
- 首關三個模型加新圖集合計 12,444,974 bytes，低於上一版三個模型的 14,631,776 bytes，約少 15%。這不是整頁下載量，也不是載入時間或 FPS 的改善百分比。
- 未新增後處理通道或陰影燈；角色基礎模型沿用既有素材，Mira／Zoey 仍是配色與裝備變體。本輪場景美術重製集中在首關。

## 自動檢查

完整指令見 [tests/README.md](tests/README.md)。涵蓋按需載入、有限並行、靜音與音訊競態、重試、資源清理、觸控座標及多指取消、直向暫停恢復、連段輸入、生成上限、分波、敵將配額重試、滿額時頭目登場重試、地表與圖集 UV、骨架共用與部件資料保留。

最終 Node 檢查 60 項通過，Python 檢查 2 項通過，六個 runtime 資產與打包規格一致。五個實際敵人 GLB 另由 vendored GLTFLoader 在 Node 解析：Minion／Warrior 9 → 2 個身體網格，其餘三種 6 → 1；逐一比對頂點、法線、UV、權重、索引、動畫變形位置及複製後骨架姿勢。這項檢查省略圖片解碼，不取代最終畫面比較。更新排程另測試 60／120 Hz、時間抖動、長停頓與重設。

尚未涵蓋：Safari、實體 Android／iPhone、長時間有聲壓力測試、四關正常難度完整通關。需要這些測試後，才能對不同裝置的長時間穩定性下結論。
