# March audio — credits

The music (market / plaza / boss / victory / defeat) is original: composed and arranged in code
(`game/scripts/audio/score.py`, `music.py`) and rendered with recorded instrument samples.
The sound effects are original layered edits of recorded CC0 sounds. Only the processed results
ship here. To rebuild, download the source packs separately (they are not in the repo) and run
`game/scripts/audio/make_audio.py --samples <folder>`.

None of these licences requires attribution. We credit the sources anyway.
