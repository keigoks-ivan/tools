# HUNTR/X 視覺改版計畫

2026-09-14。範圍：現有 Three.js 遊戲的美術呈現與介面，沿用角色資產、四關、操控、傷害與碰撞。先完成整體方向與發包規格，再實作、靜音驗收。本文件中的設計判斷是本專案的改造建議。

## 2026-09-23 第二階段：精緻動畫風（規劃與概念稿）

使用者已選定精緻動畫風，要求大幅提升且不降低現有畫質、盡量不增加負擔。先聚焦第一關；本節是製作規格，尚未套用到正式遊戲。方向稿及生成提示見 [design/README.md](design/README.md)，圖像為 [anime-direction-v2.png](design/anime-direction-v2.png)。

### 效能與品質驗收目標

- 以 `8dc4999` 的無損精簡版本為資料量基準。新素材優先替換現有素材，第一關可下載資料總量增加目標不超過 10%；超過就拆包／重用，不偷偷壓低清晰度。
- 保持現有畫面解析度、抗鋸齒、陰影設定、角色模型細節、動畫取樣；不新增常駐後處理通道或陰影燈。
- 每個美術包列出貼圖尺寸與解碼後記憶體、材質數、網格數、動畫資料量。優先讓重複店面共享素材，降低新增成本。
- 待允許實機驗收時，以同機器、同視窗、同角色、同場景比較冷啟動、記憶體與幀時間；目標是第 95 百分位幀時間增加不超過 10%。目前沒有實測，不能保證達標或宣稱 Chrome 根因已排除。
- 當前禁止開 Chrome／遊戲的限制持續有效；現階段只做美術稿、資產檢查及隔離依賴的程式測試。

### 可交給低成本模型的工作包

1. 圖集與按需載入接線：明確限制在材質載入模組，保留原始素材與失敗回退。
2. 介面套版：依定稿立繪和視覺規格修改，保留既有控制及無障礙標記。
3. 資產完整性檢查：檢查尺寸、重複材質、未使用動畫、檔案量與資料引用。
4. 主代理負責美術統一、模型／場景品質審核與效能預算；不把不明確的「整體變漂亮」直接交給廉價模型自由發揮。

## 視覺方向

霓虹獵魔、清楚的角色輪廓、冷色環境與暖色高光。主選單保留現有夜街插畫，重新構圖；遊戲畫面以角色、攻擊方向、敵方威脅為閱讀順序。削弱泛白的大面積光效，使用窄刃、亮點和短殘影建立速度感。

參考來源與借鏡範圍：

- [Devil May Cry 5／Capcom 訪談](https://blog.playstation.com/2019/03/08/old-dante-new-tricks-capcom-talks-devil-may-cry-5-out-today-on-ps4/)：動作、角色差異與連段表現優先；戰鬥資訊放畫面邊緣。
- [Scarlet Nexus／Bandai Namco 官方實機與美術](https://www.bandainamcostudios.com/products/scarlet-nexus.html)：都市奇幻配色、俐落的字級層次與切角介面。
- [Hades II／Supergiant 官方遊戲頁](https://www.supergiantgames.com/games/hades-ii/)：每個場景建立獨立色彩身分，角色與攻擊效果保持辨識度。

## 視覺規格

1. 主選單：左側大字標、右側既有畫作，清楚的開始入口；修正過期關卡文案。
2. 選角：三個並排面板，角色名、武器、操作風格與能力分層；保留 1/2/3 與點擊操作。
3. HUD：生命／能量在左上，任務置中，擊殺／連段／地圖靠右，中央戰鬥區保持清楚。聲音按鈕隨時可用。
4. 首爾：墨藍陰影、青色輪廓、洋紅招牌；黃泉：暮金主光、玫瑰陰影；天界：象牙高光、藍色遠景；虛空：深靛背景、青紫能量。主角靈氣跟隨角色。
5. 攻擊：用窄刃亮邊與漸細尾端取代大面積白色扇面，保留攻擊方向與碰撞範圍。普通命中火花短促，重击加強方向性；不增加全屏白閃。
6. 鏡頭：鎖定時適量納入敵人位置，奔跑／大絕平滑調整視角，震動逐步衰減；尊重減少動態效果設定。
7. 效能：沿用自適應解析度；火花、斬痕、衝擊波與光柱有桌機／手機數量上限；不新增常駐後處理通道或陰影燈。

## 交付檢查

- 首頁→選角→開場對話→移動與攻擊，全程靜音。
- 現有 DOM ID、素材路徑與載入版本參數完整。
- 桌面與手機橫向版面；無法實測的尺寸或設備要明列限制。
- 新燈光不能在大絕恢復後漂移；切關能套用對應光色。
- 專屬角色建模與全新動畫不屬於本輪；現有 Mira / Zoey 共用骨架的限制仍存在。
