# 素材來源

## soldier.glb
- 來源：three.js 官方範例資產 `examples/models/gltf/Soldier.glb`（github.com/mrdoob/three.js，MIT License）
- 原始模型／動作：Mixamo（Adobe）「Vanguard」角色與 Idle/Walk/Run 動作，經 three.js 專案打包散布
- 本遊戲用途：敵兵與駕駛員手臂；貼圖在執行時重新上色
